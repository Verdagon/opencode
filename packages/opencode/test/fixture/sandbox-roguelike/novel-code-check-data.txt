You are reviewing a CODE CHANGE, not the entire file. The contextified diff uses these prefixes:

- Lines starting with `-` are REMOVED code — shown for context only, not part of the new code.

Focus primarily on the `+` (added) lines, but if you notice violations in the unchanged code within the same definition (function, struct, impl block, etc.), flag those too.
